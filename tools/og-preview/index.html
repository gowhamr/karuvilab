How Open Graph Preview Works

Open Graph (OG) is a protocol originally created by Facebook that allows a webpage to become a "rich" object in social graphs. When you paste a link into Facebook, Twitter, or Slack, these platforms look for specific <meta> tags in your HTML to determine what title, description, and image to display. This tool lets you simulate that behavior without having to deploy your code first.

Why Social Metadata Matters

The visual presentation of your link directly impacts your click-through rate (CTR). A link with a compelling image and a clear, concise title is much more likely to be clicked than a plain, unformatted URL. By testing your OG tags, you ensure that your brand looks professional across all social platforms.

Key Tags Explained

  • og:title: The title of your object as it should appear within the graph.
  • og:description: A one to two sentence description of your object.
  • og:image: An image URL which should represent your object within the graph. Recommended size is 1200x630 pixels.
  • og:site_name: If your object is part of a larger web site, the name which should be displayed for the overall site.

Frequently Asked Questions

Will this work for Twitter Cards?

Yes. While Twitter has its own set of meta tags (e.g., twitter:card), it will automatically fall back to Open Graph tags if the specific Twitter tags are missing. Our generated output includes the standard OG tags that work across almost all major platforms.

What is the best size for the OG image?

The industry standard is 1200 x 630 pixels. This aspect ratio (1.91:1) ensures that your image is not cropped awkwardly when shared on high-resolution displays or mobile devices.
