What is a Slug?

A slug is the part of a URL which identifies a particular page on a website in a human-readable format. For example, in karuvilab.com/tools/slug-generator, the slug is slug-generator.

Pro Tip: Search engines prefer slugs that are short, descriptive, and use dashes to separate words.
